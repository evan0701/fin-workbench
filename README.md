# fin-workbench · 财务工作台

把金蝶、用友导出的"难用"表格，变成**可筛选、可审计的 HTML 工作台**和**可复用的自动填写技能**。

ERP 管"记进去"，这个项目管"记完之后为什么、怎么办、怎么核对"。

## 为什么做这个

财务人每月都在回答同一批问题，而传统系统答不出来：

- "这个月交了多少税？都是什么税？"
- "科目余额表导出来几百行，老板要的那几个数在哪？"
- "统计局台账又该填了，数据都在报表里，就是得人肉搬两小时。"

金蝶、用友解决"记"，这个项目解决"记完之后"：**只读分析层，不碰记账，不做直连申报**。

## 三条架构红线

1. **确定性内核**：解析、校验、取数、填写全部由代码完成，LLM 不进计算路径（LLM 只辅助写映射配置草稿和回答口径问题）。
2. **锚点闸门**：每份数据源解析后强制跑锚点校验（借贷平衡、跨月衔接、编码唯一），任一 FAIL 拒绝进入下游 —— AI 时代财务工具的第一道防线。
3. **数据不出网**：产物全部是本地单文件 HTML / xlsx，零外链；仓库里只有虚构演示数据。

## 核心机制：转换模板（mapping.yaml）

不同公司、不同软件导出的科目余额表长得不一样，但语义是收敛的。
**你只需要写一份 mapping.yaml 描述自家导出文件的样子**（哪行是表头、哪列是金额、编码名称怎么拆），
引擎把它变成标准模型，之后所有筛选、取数、填写全部通用：

```yaml
source:
  sheet: 总账科目余额表
  header_row: 4                 # 前 3 行是标题
  skip_patterns: [合计, 制表]   # 自动跳过
columns:
  code_name: { col: A, split_regex: '^(\d+)\s+(.+)$' }   # "1002　银行存款"挤一列
  opening: { debit: B, credit: C }
  period:  { debit: D, credit: E }
  closing: { debit: F, credit: G }
anchors: [opening_balance, closing_balance, codes_unique, carry_forward]
```

完整说明见 [docs/接入指南.md](docs/接入指南.md)。

## 快速开始

```bash
git clone <本仓库> && cd fin-workbench
python3.12 -m venv .venv
.venv/bin/pip install -e ".[dev]"
bash demo/run_demo.sh
```

`run_demo.sh` 会用**星澜科技虚构数据集**跑完全流程，产出：

| 产物 | 说明 |
|---|---|
| `demo/输出/科目余额筛选台账.html` | 可搜索、可筛选、逐格溯源的余额表工作台 |
| `demo/输出/支付税费台账.html` | 本月实缴/未缴分税种台账（多个月并列） |
| `demo/输出/统计月度台账_2025-09_成品.xlsx` | 由铸造技能自动填写 + 复核清单 |
| `demo/输出/资金计划执行台账.html` | 银行流水 ↔ 资金计划两级匹配：1:1 精确 + 1:N 聚合 + 关键词桶，双边差异一目了然 |

## 体系地图

```
fincore/            确定性内核：mapping.yaml → 标准模型 → 锚点校验 → HTML 视图
  └ bank/           银行流水：bank mapping.yaml → 标准流水 → 两级匹配 → 资金计划执行台账
skills/
  fin-workbench/    总入口技能（触发路由）
  fin-scout/        元技能·发现者：识别重复劳动 → 判定 → 移交铸造（观察台账只增不删）
  fill-forge/       铸表技能：把"每月重复填表"铸造成可复用技能（五步流程 + 回填考试）
forged/
  stat-monthly-ledger/  第一个铸出的技能：统计月度台账（已通过上期回填考试，差异清零）
demo/               星澜虚构数据：乱格式导出样本（余额表+银行流水）+ 台账模板 + 一键脚本
tests/              pytest：解析 / 锚点 / 视图 / 匹配 / 端到端 / 回填考试
```

## fill-forge：技能铸造器（本项目最有意思的部分）

如果你每月都要填某张表（统计局台账、国资快报、资金计划表……），不用每次教 AI：

1. 给 fill-forge 三样材料：目标表模板、数据源导出、上期人工版
2. 它产出映射草稿 + 待确认问题清单，你逐条确认冻结成 mapping.yaml
3. 它铸造一个标准骨架的填写技能（SKILL.md + 映射 + 确定性代码 + 口径文档 + 测试）
4. **回填考试**：用上期数据填写，对照上期人工版，逐格差异清零才允许上岗
5. 之后每月：拖入导出文件 → 成品 + 复核清单

详见 [docs/铸造指南.md](docs/铸造指南.md)。
