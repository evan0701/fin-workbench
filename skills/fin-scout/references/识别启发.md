# 识别启发：财务工作里的常见重复模式

供 fin-scout 识别时对照。每条含"典型信号"和"铸造价值"，新发现的模式回写到本文件（只增不减）。

## 高价值模式（见到就记台账）

| 模式 | 典型信号 | 铸造价值 |
|---|---|---|
| 周期性报送表 | "每月 X 号前要报""统计局/国资/集团要的" | 高：格式固定、口径可文档化、漏报有后果 |
| 月度问答套装 | 老板每月固定问同一批数（税费分项、资产负债率、现金流） | 高：源表稳定，视图一次建成月月复用 |
| 导出-清洗-汇总 | 每次都"导出 X 表 → 删几列 → 透视 → 贴到 Y" | 高：四段模式最典型，AI 生成映射草稿的成功率也最高 |
| 固定核对清单 | 每月结账前按同一清单核对勾稽/余额 | 中高：可铸成"体检技能"，输出差异清单 |
| 周期性对账 | 银行流水 vs 账面、平台账单 vs 收款 | 中高：源格式各异，正好吃"转换模板"协议 |
| 数据搬运下载 | 从固定网站/系统周期下载报表再整理 | 中：下载环节可用浏览器自动化（gstack /browse 模式可借），清洗入库后接铸造 |

## 低价值/排除模式（看到就跳过，不记台账）

| 模式 | 为什么不铸 |
|---|---|
| 年度一次性动作 | 频次不够，且明年规则大概率已变 |
| "帮我看看这个表" | 无固定产物，属即席分析 |
| 口径每月在变的报表 | 模式漂移，固化了也过不了回填考试 |
| 涉及人工判断为主的动作（如审核意见撰写） | 可辅助但不适合"确定性内核"骨架，别硬铸 |

## 频次信号的口语对照

- 强信号：每个月 / 每季度 / 每次报 / 月底 / 结账前 / 又要填了 / 每回都得
- 弱信号（记录但标注观察）：最近几次 / 上次也是这样 / 好像经常
- 非信号：这次 / 今天（无周期含义，除非用户明说下月还有）
