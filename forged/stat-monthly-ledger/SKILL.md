# 统计月度台账填写（fill-forge 铸造 · 演示）

> 铸造记录：2026-10-04 由 fill-forge 铸成。回填考试：2025-08 期数据对照人工版，14 个数据单元格差异清零。

## 触发条件

用户给出台账所需的当月科目余额表导出文件（金蝶风格），要求填写统计月度台账。

## 使用方法

```bash
# 例行填写（以 2025-09 为例）
.venv/bin/python forged/stat-monthly-ledger/fill.py \
  --source "demo/示例导出/科目余额表_2025-09_乱格式.xlsx" \
  --period 2025-09 \
  --out "demo/输出/统计月度台账_2025-09_成品.xlsx"

# 回填考试模式（对照人工版）
.venv/bin/python forged/stat-monthly-ledger/fill.py \
  --source "demo/示例导出/科目余额表_2025-08_乱格式.xlsx" \
  --period 2025-08 \
  --out out/回填考试.xlsx \
  --check "demo/统计台账模板/统计月度台账_2025-08_人工版.xlsx"
```

## 输入

| 材料 | 位置 | 说明 |
|---|---|---|
| 数据源 | 命令行 `--source` | 当月科目余额表导出（乱格式金蝶风格，经 `demo/mapping_jinDie.yaml` 解析） |
| 目标模板 | `demo/统计台账模板/统计月度台账_模板.xlsx` | 空白台账（虚构演示格式） |
| 映射配置 | `mapping.yaml`（本目录） | 目标单元格 ↔ 取数口径，经人工确认冻结 |

## 输出

1. **成品 xlsx**：已填本期数与数据来源说明
2. **复核清单 md**（成品同目录）：逐格标注 直接取数 / 衍生计算 / 取数源，供报送前人工复核

## 铁律（继承自 fill-forge，不可删改）

1. 锚点不全绿，不填报：数据源解析锚点任一 FAIL → 拒绝填写并输出校验报告
2. 零信任独立取数：数值全部由代码从标准模型计算，衍生公式与 `references/口径说明.md` 逐字一致
3. 只填数值不动格式：目标单元格如有公式则跳过并标注
4. 只增不严：填写错误反馈一律新增校验规则，不放宽旧规则

## 红线

本台账为虚构演示。真实报送前必须人工复核成品与复核清单；本技能不做任何自动报送。
