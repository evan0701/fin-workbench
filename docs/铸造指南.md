# 铸造指南：用 fill-forge 把重复填表变成技能

适用场景：每月/每季要填一张表（统计局台账、国资快报、集团底稿、资金计划表……），
数据可以从科目余额表、财务报表等导出文件取得。

## 五步流程（详细版见 skills/fill-forge/SKILL.md）

1. **收集材料**：目标表模板 + 数据源导出 + 上期人工成品（强烈建议：它是考试的考卷）
2. **生成映射草稿**：AI 列出口径问题清单（期间口径？含税？累计/当期？），对每个待填字段给出取数建议；拿不准的必须问，禁止猜
3. **人工确认**：渲染 Markdown 审核表（目标单元格 ↔ 来源 ↔ 口径 ↔ 验证值），逐条确认后冻结成 `mapping.yaml`
4. **铸造技能包**：统一骨架 `SKILL.md + mapping.yaml + fill.py + references/ + tests/`，照 `forged/stat-monthly-ledger/` 抄结构
5. **回填考试**：用上期数据源填写上期表，对照上期人工版，差异清零才上岗；考试结果写进 SKILL.md

## fill.py 的标准动作（每个铸出的技能必须一致）

```python
# 1. 解析数据源 → 标准模型 + 锚点；锚点任一 FAIL → 拒绝填报（铁律 1）
# 2. 打开目标模板；目标单元格有公式 → 跳过并标注（铁律 3）
# 3. direct 行取 mapping 指定科目与字段；formula 行调 FORMULAS 字典（口径见 references/口径说明.md）
# 4. 保存成品 + 输出复核清单（每个格子标注 直接取数/衍生计算/来源）
# 5. --check 模式：对照人工版逐格比对，任何差异 > 0.005 → 考试不通过
```

## 四条铁律（继承自 fin-audit，不可删改）

1. **锚点不全绿，不填报**
2. **零信任独立取数**：数值全部由代码计算；衍生公式与口径文档逐字一致
3. **只填数值不动格式**：不碰目标表的公式、格式、隐藏行列
4. **只增不严**：每次填写错误都沉淀为新校验规则，禁止放宽

## 什么情况下不要铸造

- 一次性填的表（每年一次）→ 直接让 AI 辅助填，不值得铸造
- 数据源每次都要人肉加工超过 30 分钟 → 先解决数据源接入（见 docs/接入指南.md）
- 对外报送且口径经常变 → 先固定口径文档，再铸造
